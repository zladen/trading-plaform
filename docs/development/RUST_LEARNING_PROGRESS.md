### 2026-11-27 — Week 1, Day 1 — Этап D завершён

Все четыре вопроса отвечены. Проверено на Cargo 1.97.1.

**Вопрос 1 — верно.** Предупреждение, подставляется `2015`. Точный текст:
``warning: `package.edition` is unspecified, defaulting to `2015` while the latest is `2024` ``

**Вопрос 2 — верно.** «Это предупреждение, `cargo build` завершится успешно,
бинарник создастся, код в main.rs для 2015 валиден». Совпадает с проверкой:
exit=0, бинарник создаётся, программа печатает `price-feed запущен`.

**Вопрос 3 — по сути верно, но общо.** «Ломает совместимость кода, может не
работать или работать неправильно». Направление правильное. Не назван конкретный
механизм; проверено, что он двойной:
- жёсткий отказ компиляции: `gen` в edition 2024 — зарезервированное слово,
  `let gen = 1;` собирается в 2015/2018 и падает в 2024;
- молчаливое изменение поведения: код компилируется в обеих редакциях, но
  семантика различается — такое не отловить без знания разницы.
Курсант воспроизвёл только первую половину.

**Вопрос 4 — верно.** Манифест:
```toml
[package]
name = "price-feed"
version = "0.1.0"
edition = "2024"
```
Проверено: `cargo build` без предупреждений, exit=0, метаданные показывают
`edition: 2024`, `version: 0.1.0`.

**Оценка Этапа D: 22/25.** Минус за неконкретность вопроса 3 — назван эффект, но
не механизм, и не упомянут более опасный случай молчаливого изменения поведения.
Формулировка «ломает совместимость» без примера слишком общая, чтобы считать
понимание подтверждённым полностью.
